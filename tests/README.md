# tests

## Overview

Unit tests of the annotation model and every writer.

## Components

| Component | Description |
| --------- | ----------- |
| [conftest.py](./conftest.py) | Placeholder image helper and single-label and multi-label dataset fixtures. |
| [test_annotation.py](./test_annotation.py) | Validation of labels, images and datasets. |
| [test_writers.py](./test_writers.py) | Output of each format writer. |

## Examples

```bash
pytest
```
